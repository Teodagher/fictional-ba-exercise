# Fictional Exercise — Business Analyst AI Workshop

> ⚠️ **Fictional training material.** Everything in this repository is invented for a Business Analyst training workshop. It is **not** affiliated with, endorsed by, or representative of Euronext or any other real company, system, team, person, or decision. All names, people, figures, dates, systems, and requirements are made up. Public market vocabulary (ISIN, MIC codes, trading phases, EU regulations) is used only to make the case study realistic.

## The case study

A fictional exchange group wants its investor web and mobile app to send **informational alerts** (price crossing a level, unusual volume) by in-app inbox, email, and mobile push. Alerts give information only, never investment advice.

## What's inside

| Folder | Content |
|---|---|
| `00-project-brief.md` | Project overview: goals, figures, stakeholders, scope, budget |
| `requirements/` | Scoping note, business / functional / non-functional requirements, meeting notes, review comments |
| `features/` | Raw discovery input (interview quotes, support ticket figures) |
| `change-request/` | CR-01: a new request to add corporate-action notifications |
| `reference/` | Glossary, market context, personas, system landscape |
| `.github/agents`, `.github/skills` | Empty — participants create their own agents and skills here |

## Exercises

1. Build a skill that turns the `requirements/` folder into **features documentation**.
2. Build a skill that turns that documentation into a **branded presentation**.
3. Build an agent that uses both skills, then find and add the missing skill so it can produce an **Excel impact analysis** and a summary presentation for `change-request/`.
