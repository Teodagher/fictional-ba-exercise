# Feature Discovery Input

This is a short discovery input for feature documentation. It is intentionally not a completed feature specification.

## Capability themes

- Configure and manage an alert rule.
- Evaluate price and volume conditions.
- Deliver a notification through selected channels.
- Show notification history.
- Manage consent and channel preferences.
- Investigate outcomes through support tooling.
- Monitor service health and maintain an auditable record.

## User language captured in discovery

- "I want to know when something I follow crosses a level I care about."
- "I need to pause alerts when I am away without deleting all my setup."
- "If I receive an email and a push notification, I need to understand whether they refer to the same event."
- "Support should be able to tell me what happened without asking for unnecessary personal information."

## Documentation questions

- What is the smallest useful first-release slice?
- Which rules and states must be visible to the user?
- What happens when an instrument becomes ineligible?
- What is the expected behavior when a channel provider is unavailable?
- What evidence is needed for compliance, privacy, and support?
- Which acceptance criteria can be tested from the stated requirements?
